# Sistema de Ventas

## 📌 Descripción General

Este proyecto consiste en el desarrollo de un sistema de ventas enfocado en la gestión de productos, usuarios y transacciones. Está construido con una arquitectura moderna basada en backend con FastAPI y una base de datos PostgreSQL desplegada en Render.

El sistema busca ser escalable, mantenible y preparado para integrarse con un frontend desarrollado en Flutter.

---

## 🏗️ Arquitectura del Proyecto

El backend está desarrollado con:

* **FastAPI** como framework principal
* **SQLAlchemy** para el manejo de base de datos
* **PostgreSQL** como motor de base de datos
* **Uvicorn** como servidor ASGI
